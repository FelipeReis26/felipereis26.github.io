At work

I'm a Service Desk Analyst III at a global sports betting and gaming company. These tools are internal, so I can't show screenshots. Here's what each one does and what it changed.

New hire access

~23access tickets from one new hire request.

Google Apps Script, JavaScript, Jira APIs, built with Claude

Every new starter used to mean about 23 access tickets raised by hand. I went through 1,600 old tickets to work out what each role needs and who approves it, then turned that into rules. Now one request raises the whole batch. It's been in production since July 2026 and now runs from the desk's New hire hub.

Vendor status dashboard

81vendor status pages watched.

Google Apps Script and Slack, moving to Node and Docker

We were paying for a service that watched vendor status pages. I built my own and ran the two side by side for a few weeks. Mine kept up with the paid one and caught several outages it missed. One was an 8 hour outage at a Tier 1 vendor. The $4,000 a year subscription is set to be cancelled. I'm rebuilding the dashboard in Node and Docker to run on AWS.

The desk's automation hub

Morning triage, ticket QA and the team's numbers in one app.

Google Apps Script web app, JavaScript, Jira and Slack APIs, GitHub

The hub is one web app for the desk's morning triage, ticket QA and live team numbers. Anything that writes to Jira shows you the change and asks first. It's had dozens of releases, and I presented it to the team at a company offsite. It's now being moved onto the company's AWS platform.

Knowledge base cleanup

~700pages in the desk's knowledge base.

Confluence, KCS, Jira automation. Co-leading, still going

It had no owners and no review cycle. A colleague and I are cleaning it up the KCS way. I've reviewed over 100 pages myself and written 19 guides and runbooks. We've also written a page template that names an owner for every page.

Scheduled checks

~14checks that run whether anyone remembers them or not.

Claude, scheduled agents, Jira, Slack and Confluence APIs

The small checks that keep a desk healthy only happen when someone remembers. I set about 14 of them to run on a schedule. They check the weekly P1 handover, catch customer replies on closed tickets and fix missing priorities. In November I folded ten of them into one morning brief.

Tessera

Web app and iPhone app · React, TypeScript, Supabase, Vercel, Capacitor · Open it

My friends and I play the same daily puzzles, so I built one place for them. Tap a game to play it, and when you come back it ticks itself off. Your group shares one board. Every game keeps its own streak.

The tricky part was telling a real game from a quick glance. Only the page actually going hidden counts. It still works if iOS closes the page mid game. It runs on Supabase, and every table has row level security with database tests.

Final Whistle

Football match predictor · Python, JavaScript, GitHub Actions

It predicts home, draw and away chances for the top leagues in ten European countries and puts them beside the bookmakers' odds.

I held it to being honest. On 4,194 matches it never saw, it comes close to the bookmakers but doesn't beat them. The write up says that plainly. A GitHub Actions job logs every prediction before kickoff. The phone page is password protected, so there's no link.

GILD

Budget app · React, Capacitor, on my iPhone · Live app · Code

My budget app. On payday it splits my pay across bills, savings and spending limits, and the home screen shows what's safe to spend. Bank statements import straight in.

Nothing leaves the phone. There's no server, no account and no bank connection.

Tripsy

Trip planner · HTML, CSS, JavaScript, Vercel functions, an iPhone app

A trip planner my partner and I use. Each trip is its own page, and the home page works out our leave days. New trips go in through a form that commits the page straight to GitHub.

We each have a packing list per trip, and GILD reads our trip costs from it. It holds our real travel dates, so it sits behind a login and I don't link to it.
